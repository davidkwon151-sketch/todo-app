# Search Feature Spec

## 목적
할 일이 많아졌을 때 사용자가 Todo 제목으로 필요한 항목을 빠르게 찾을 수 있도록 합니다.

## 범위
- Todo 제목을 검색합니다.
- 검색창은 하나만 제공합니다.
- 검색어를 입력하면 즉시 목록을 필터링합니다.
- 검색어를 모두 지우면 전체 Todo 목록을 다시 표시합니다.

## 제외 범위
- 검색어 저장
- 검색 결과 개수 표시
- 완료 상태, 우선순위, 마감일 기준 검색
- 정렬, 필터 탭, 하이라이트 표시

## UI
- Todo 입력 폼과 목록 사이에 검색창을 배치합니다.
- 검색창 placeholder는 `할 일 검색`으로 표시합니다.
- 검색창이 비어 있으면 기존 목록과 동일하게 전체 Todo를 표시합니다.

## 동작
- 검색은 Todo의 `title` 필드만 대상으로 합니다.
- 검색은 대소문자를 구분하지 않습니다.
- 검색어 앞뒤 공백은 무시합니다.
- 검색 결과가 없으면 빈 목록 상태를 표시합니다.
- 검색은 화면 표시만 바꾸며 Todo 데이터와 저장된 값은 변경하지 않습니다.

## 완료 조건
- 사용자가 검색창에 Todo 제목 일부를 입력하면 일치하는 Todo만 목록에 보입니다.
- 검색어 대소문자가 달라도 같은 제목을 찾을 수 있습니다.
- 검색어를 지우면 전체 Todo 목록이 다시 보입니다.
- 검색 중에도 기존 Todo 추가, 완료/미완료 전환, 삭제, 저장, 남은 할 일 개수 표시가 계속 동작합니다.
