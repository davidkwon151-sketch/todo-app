# Todo 완료 상태 필터 명세

## 목적
Todo가 많아졌을 때 사용자가 전체 목록, 진행 중 Todo, 완료 Todo를 간단히 구분해서 볼 수 있게 합니다.

## 범위
- Todo 완료 상태를 기준으로 목록 표시를 필터링합니다.
- 필터 옵션은 `전체`, `진행 중`, `완료` 3가지만 제공합니다.
- 기존 Todo 추가, 완료/미완료 전환, 삭제, 브라우저 저장, 남은 할 일 개수 기능은 유지합니다.

## 동작
- 기본 필터는 `전체`입니다.
- `전체` 선택 시 모든 Todo를 표시합니다.
- `진행 중` 선택 시 완료되지 않은 Todo만 표시합니다.
- `완료` 선택 시 완료된 Todo만 표시합니다.
- 필터는 Todo의 저장 데이터 자체를 변경하지 않고 화면에 보이는 목록에만 적용합니다.
- 필터가 적용된 상태에서도 Todo의 완료/미완료 전환과 삭제는 기존 방식대로 동작합니다.

## 제외 사항
- 검색 기능은 포함하지 않습니다.
- 카테고리, 우선순위, 날짜 필터는 포함하지 않습니다.
- 필터 상태의 브라우저 저장 여부는 이번 범위에 포함하지 않습니다.

## 완료 조건
- 앱을 처음 열면 `전체` 필터가 선택되어 있고 모든 Todo가 보입니다.
- `진행 중` 필터를 선택하면 미완료 Todo만 보입니다.
- `완료` 필터를 선택하면 완료 Todo만 보입니다.
- 필터를 바꿔도 Todo 추가, 완료/미완료 전환, 삭제, 저장 기능이 깨지지 않습니다.
