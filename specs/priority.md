# 우선순위 기능 Spec

## 목적

할 일이 많아졌을 때 사용자가 중요한 일을 먼저 알아볼 수 있도록 각 할 일에 우선순위를 표시합니다.

## 범위

- 할 일 추가 시 우선순위를 선택할 수 있습니다.
- 우선순위는 `높음`, `보통`, `낮음` 3단계로 둡니다.
- 기본값은 `보통`입니다.
- 할 일 목록에는 제목과 함께 우선순위가 보입니다.
- 기존 기능인 추가, 완료/미완료 전환, 삭제, 브라우저 저장, 남은 개수 표시는 유지합니다.

## 제외 범위

- 우선순위별 자동 정렬은 이번 기능에 포함하지 않습니다.
- 우선순위별 필터링이나 검색은 이번 기능에 포함하지 않습니다.
- 마감일 기능은 이번 기능에 포함하지 않습니다.

## 화면 동작

1. 입력창 옆에 우선순위 선택 메뉴가 보입니다.
2. 사용자가 할 일을 입력하고 우선순위를 고른 뒤 `추가`를 누릅니다.
3. 새 할 일이 목록 맨 위에 추가됩니다.
4. 목록의 각 할 일에는 우선순위 표시가 함께 보입니다.
5. 저장된 할 일을 다시 열면 기존 우선순위도 유지됩니다.

## 데이터

각 할 일 데이터는 기존 값에 `priority` 값을 추가합니다.

```js
{
  id: "고유 ID",
  title: "할 일 제목",
  completed: false,
  priority: "medium"
}
```

우선순위 값은 다음처럼 저장합니다.

- `high`: 높음
- `medium`: 보통
- `low`: 낮음

기존 저장 데이터에 `priority`가 없으면 `medium`으로 처리합니다.

## 완료 조건

- 할 일을 추가할 때 우선순위를 선택할 수 있습니다.
- 새로 추가한 할 일에 선택한 우선순위가 표시됩니다.
- 새로고침 후에도 우선순위가 유지됩니다.
- 기존 저장 데이터처럼 우선순위가 없는 항목도 오류 없이 `보통`으로 표시됩니다.
- 완료 체크, 삭제, 남은 할 일 개수 표시가 기존처럼 동작합니다.
